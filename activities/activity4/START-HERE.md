# Activity 4 — Start here

Choose the handout for your machine:

- **Linux x86-64 (Ubuntu 24.04 baseline):** read [activity4.linux.md](activity4.linux.md), edit `simpson.linux.cpp`, and use `setup_linux.sh` and `run.sh`.
- **macOS on Apple silicon:** read [activity4.M5.md](activity4.M5.md), edit `simpson.M5.cpp`, and use `run.M5.sh`.

Both versions have the same tasks and grading: 72 automated + 28 manual points.
Submit only your chosen platform's C++ solution to the programming assignment.
Submit all 54 measurements, the plot, and a PDF of answers and machine details
to the written-work submission. Keep the starter for the other platform out of
your code upload. Follow your platform handout for installation and filenames.
